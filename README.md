# Simple Snake Game

A simple 2D Snake game built using Python and the Pygame library. This is one of my early projects to practice Python programming, learning how to handle game loops, movements, and simple collision logic.

## Features
* Simple snake movement using keyboard arrows.
* Different items like Food, Bonus, Poison, and Slow items.
* Score and speed counters on the screen.
* Game over screen with sound effects.

## How to Run
1. Make sure you have Pygame installed:
   ```bash
   pip install pygame
   ```
2. Run the `main.py` file to start the game.
